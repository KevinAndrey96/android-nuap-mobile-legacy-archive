## 📌 Historical Overview

This repository preserves the historical cross-platform Xamarin.Forms partner store and courier mobile application originally developed for the Nuap beverage delivery platform. It handled order dispatch states and bodega fulfillment.

All components, database schemas, and workflows have been merged and modernized into the primary repository: **[android-nuap-delivery-platform](https://github.com/KevinAndrey96/android-nuap-delivery-platform)**.
